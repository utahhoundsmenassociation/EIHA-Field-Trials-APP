🎲 Heat Tools:
Treeing Contest Score Entry

Each dog is released for 30 seconds and scored by three judges (J1, J2, J3). The three scores are averaged and doubled for the 1-minute equivalent — highest average ranks first.

Iron Dog Jackpot

Last dog remaining in the circle wins — mark 1st / 2nd / DQ. A dog is DQ’d if it leaves the circle. Tap a marked button again to clear it. Jackpot payout is on the Scoreboard tab.

Big Bear Race Jackpot

Individual scent-drag race — 1st to tree wins. Mark 1st / 2nd / DQ. Jackpot payout is on the Scoreboard tab.

Bear Pack Races Jackpot Event

Pack jackpot — separate 3-Dog and 5-Dog races. All dogs must finish and tree to qualify; fastest qualifying time wins. Enter finish times in HH:MM:SS format.

Add Pack Team
Enter the team name, handler, pack size, and dogs in this pack.

🌊 Water Races

Turn on to add the six water classes (Puppy, Junior, Senior, Old Dog, Powderpuff, Kids) alongside the drag classes. Water races run 6 dogs per start box and go straight from qualifying to a final — no semifinal ladder.

Scoring is the same as a drag: 1st / 2nd to pass the T-poles = 1st / 2nd Line, then 1st / 2nd to bark the coon = 1st / 2nd Tree. A class with too few entries runs straight to a silver-points final.

Dog Registry Permanent IDs

Every dog + owner pair gets an ID the first time it registers and keeps it for good, across spring and fall. Use these IDs in the club's year-end points sheet — they're in the Dog Registry tab of the Excel export.

Merge a duplicate

If a typo created a second ID for a dog that already had one, merge them. Everything in the current event — heats, scores, collars, contact details — is repointed at the ID you keep, and the duplicate is retired with a pointer so older exports still resolve.
